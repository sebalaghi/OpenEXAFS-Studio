OpenEXAFS Studio

CIF / structure → Feff8L → XrayLarch path modeling → FEFFIT

View on GitHub Download source Deploy browser edition

Structure to Feff

Load CIF/structure files, choose absorber site and edge, generate an editable Feff8L input, and run a conventional EXAFS calculation.

Path browser

Inspect degeneracy, Reff, geometry, NLEG, and filter single or multiple scattering paths.

k and R-space preview

Plot chi(k), k-weighted spectra through k³, and complex Fourier-transform components. Export CSV and publication figures.

Larch FEFFIT

Load experimental XAS, process with Larch pre_edge/autobk/xftf, and fit selected FEFF paths in R space.

Scientific scope

Feff8L is used here as an EXAFS engine. This project does not redistribute FEFF9 and does not claim Feff8L as a full FEFF9 XANES replacement.
