Structure to Feff8L

Load a structure, choose absorber site and edge, generate FEFF8-style input, and run Feff8L.

Path browser

Inspect degeneracy, Reff, geometry, NLEG, and filter single or multiple scattering paths.

k and R-space preview

Preview FEFF paths before fitting and export numerical plot data.

Artemis export

Export the original Feff8L path files and FEFF metadata in an Artemis-ready folder or ZIP.

Scientific scope

OpenEXAFS Studio generates FEFF8L scattering paths. Quantitative EXAFS fitting is intentionally left to Artemis or another dedicated fitting environment.
