OpenEXAFS Studio source code is MIT licensed. It depends on external scientific software packages,
including XrayLarch, Feff8L, pymatgen, larixite, NumPy, Matplotlib, PySide6, and optionally Streamlit.
Each dependency remains subject to its own upstream license and attribution requirements.

This repository intentionally does not include FEFF9 binaries, FEFF9 license keys, or licensed FEFF9
components.
