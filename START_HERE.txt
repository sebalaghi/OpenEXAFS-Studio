OpenEXAFS Studio v0.3.0

Windows desktop:
  First install / repair: INSTALL_AND_RUN.bat
  Normal launch:          RUN_GUI.bat
  Diagnostic:             DIAGNOSTIC.bat

Main workflow:
  Structure -> Feff8L -> path inspection / preview -> Artemis export

The built-in fitting section has been removed. Version 0.3.0 focuses on generating
original Feff8L scattering-path files and packaging them for import into Artemis.
